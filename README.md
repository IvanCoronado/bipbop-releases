# BipBop

**One AirPod. A whole arcade.**

A native Mac console of arcade minigames controlled with an AirPod. Move to aim, choose microphone taps or experimental native presses to fire, and unlock games by beating their target scores.

## Download

[**Get the latest version**](https://github.com/IvanCoronado/bipbop-releases/releases/latest)

Download the `BipBop-VERSION-macOS-arm64.zip` asset, unzip it, and move `BipBop.app` to Applications. The release also includes installation instructions in `LEEME.txt`.

- Apple Silicon Mac (M1 or later), macOS 14 or later.
- AirPods compatible with head tracking, connected to the Mac.
- English interface. 30 games available; the remaining slots in the 500-game mosaic are marked **Coming Soon**.

This is an experimental build with a local ad-hoc signature, not Apple notarization. macOS may block the first launch; see the release instructions and [Apple's guidance](https://support.apple.com/102445). Native media controls depend on the AirPods model and configuration.

## Updates

From BipBop 0.8.0 onward, use **BipBop → Check for Updates…** or the button in **About BipBop**. Automatic checks are optional. Sparkle verifies signed updates before installation; records, unlocks, and pending games remain on your Mac.

Versions older than 0.8.0 need one manual installation to add the updater.
