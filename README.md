# BipBop

**One AirPod. A whole arcade.**

A native Mac arcade with 100 games controlled with AirPods. Wear them to play with your head, or hold one as a controller. Move to aim, choose microphone taps or experimental native presses to act, and earn bronze, silver and gold medals.

## Download

[**Get the latest version**](https://github.com/IvanCoronado/bipbop-releases/releases/latest)

The current direct download is **BipBop 0.9.0 (build 20)**. Download `BipBop-0.9.0-macOS-arm64.zip`, unzip it, move `BipBop.app` to Applications, and double-click the app. The release also includes installation instructions in `LEEME.txt` and a `SHA256SUMS.txt` file for checking the download.

- Apple Silicon Mac (M1 or later), macOS 14 or later.
- AirPods compatible with head tracking, connected to the Mac.
- 100 games included, with an interface in English and Spanish.

This version is signed with **Developer ID**, uses the hardened runtime, and is **notarized by Apple**, with the notarization ticket stapled to the app. macOS may ask you to confirm the first opening of an app downloaded from the Internet; choose **Open**. If you see a different security warning, download the latest version from this repository and contact support. See [Apple's guidance](https://support.apple.com/102445) for details.

Native media controls remain experimental and depend on the AirPods model and configuration. No account or Internet connection is required to play. Explore the games and setup instructions at [bipbop.site](https://bipbop.site/).

## Updates

From BipBop 0.8.0 onward, use **BipBop → Check for Updates…** (**Buscar actualizaciones…** in Spanish) or the button in **About BipBop**. Automatic checks are optional. Sparkle verifies signed updates before installation. Updating keeps saved records, medals, unlocks and controller settings on your Mac.

Versions older than 0.8.0 need one manual installation to add the updater.

Games in progress stay in memory only: they cannot be resumed after quitting the app or installing an update. Saved progress is local and does not sync across devices.
